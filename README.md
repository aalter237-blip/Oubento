# Oubento

نظام تشغيل مكتبي متكامل للهاتف، مستوحى من **Ubuntu 24.04 LTS (Noble Numbat)** وبيئة **GNOME / Yaru**.

يعمل كتطبيق ويب تقدّمي (PWA) يمكن تثبيته على الشاشة الرئيسية واستخدامه يومياً دون اتصال بعد أول تحميل.

## ماذا يتضمن

- شاشة إقلاع، قفل، سطح مكتب، شريط علوي، رصيف تطبيقات
- إدارة نوافذ، نظرة عامة، إعدادات سريعة، إشعارات
- نظام ملفات حقيقي محفوظ محلياً (IndexedDB)
- طرفية Unix شبه كاملة (`neofetch`, `apt`, `ls`, `cd`…)
- متصفح، ملفات، إعدادات، مركز برمجيات
- محرر نصوص، مستندات، جداول
- كاميرا، معرض، موسيقى، فيديو، مسجّل
- تقويم، ساعة، طقس، خرائط، بريد، رسائل، جهات
- مراقب نظام، أقراص، سجلات، محدّث
- ألعاب: ألغام، ثعبان، 2048

كلمة مرور اختيارية لشاشة القفل: `ubuntu`

## التشغيل

افتح `index.html` عبر خادم محلي، أو:

```bash
python3 -m http.server 8080 --bind 0.0.0.0
```

## التثبيت على الهاتف (بديل APK)

بدون Android SDK لا يمكن توقيع حزمة APK أصلية في هذه البيئة. التطبيق جاهز كـ **PWA**:

1. افتح الرابط في Chrome على أندرويد
2. القائمة ← **إضافة إلى الشاشة الرئيسية** / تثبيت التطبيق
3. يفتح بملء الشاشة كنظام مستقل

للبناء لاحقاً كـ APK / TWA استخدم [Bubblewrap](https://github.com/GoogleChromeLabs/bubblewrap) أو Android Studio مع WebView يشير إلى نفس الملفات.
